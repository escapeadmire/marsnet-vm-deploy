MarsNet · Ubuntu VM

VM setup

This installer adds Tailscale (with Tailscale SSH), Homebrew, GitHub CLI, and OpenCode to an Ubuntu VM. You authenticate to Tailscale and OpenCode yourself in the terminal.

Run it from the VM

Download and inspect the script before running it. It requires a sudo-capable, non-root Ubuntu user and an interactive terminal.

curl -fsSLo /tmp/marsnet-vm-install.sh https://vm-deploy.mars-net.ca/install.sh
less /tmp/marsnet-vm-install.sh
bash /tmp/marsnet-vm-install.sh
View installer source

What happens

  1. Installs Homebrew prerequisites and Homebrew for your user.
  2. Installs gh and OpenCode through Homebrew.
  3. Installs Tailscale, prompts you to authenticate, and enables Tailscale SSH.
  4. Opens OpenCode so you can connect a provider using /connect.

Review before running: this is a public installer. It downloads the official Tailscale and Homebrew install scripts over HTTPS, and installs current Homebrew packages. Do not run it if you do not trust the source.

After verifying Tailscale access, restrict or close inbound port 22 in Azure. Tailscale SSH access is controlled by your tailnet policy.
